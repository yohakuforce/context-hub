# v0.1.0 — Initial OSS release

## Overview

Context-Hub is an MCP-native personal context integration server that helps you
collect, store, and query your team's scattered knowledge. It stores documents and
issues in a local SQLite database using sqlite-vec for vector search and FTS5 for
full-text search, then exposes everything through a single FastAPI + MCP endpoint.
Licensed under Apache 2.0, it is the OSS counterpart of koya's internal
"Personal Context Engine" (yohakuforce/koya-brain).

## Highlights

- **sqlite-vec vector search** — 768-dim dense embeddings via BGE-M3 (or mock
  hash-based embeddings for zero-install quickstart)
- **FTS5 full-text search** with Reciprocal Rank Fusion (RRF) hybrid scoring
- **Typer CLI** — `init`, `serve`, `ingest`, `query`, `migrate` subcommands
- **MCP server** as first-class entry point (`context-hub serve --mcp-only`),
  compatible with Claude Desktop and AI-PM integrations
- **APScheduler** background sync with memory, SQLite, and PostgreSQL backends
- **Three-profile settings system** — `quickstart`, `personal`, `production`
- **Protocol-based repository pattern** — swap SQLite for PostgreSQL/pgvector
  by changing a single `ADAPTER` environment variable; no application code changes
- **Production safety gate** — `migrate` requires explicit confirmation in
  `APP_ENV=production`; bypass with `--yes` in CI

## Installation

```bash
pipx install yohakuforce-context-hub
context-hub init --profile quickstart
```

> The `quickstart` profile uses mock (hash-based) embeddings and a local SQLite
> database — no GPU, no external API keys required.

## Quickstart

```bash
# Start the HTTP + MCP server
context-hub serve

# Verify it is running
curl http://localhost:8000/health
```

The MCP endpoint is available at `http://localhost:8000/mcp` for Claude Desktop
integration. See `examples/mcp/mcp.json` for a ready-to-use configuration template.

## Requirements

- Python 3.12+
- SQLite 3.38+ (ships with macOS 12+ and most modern Linux distributions)

For the `embedding` extra (BGE-M3 local inference):

```bash
pipx install "yohakuforce-context-hub[embedding]"
```

For PostgreSQL/pgvector support:

```bash
pipx install "yohakuforce-context-hub[postgres]"
```

## What changed from 0.1.0a1

This release promotes the alpha to stable with the following additions:

- MCP server entry point and `/mcp/version` endpoint
- `--mcp-only` / `--http-only` flags on `serve`
- Namespace rename: `src/` → `context_hub/` (T-20260516-007a)
- Removed authentication backdoor from P3 development phase
- `.env` file permissions hardened to `0600` on `init`
- `migrate --dry-run` masks database passwords in logs
